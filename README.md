# DaAuto

Одностраничный сайт компании DaAuto (Варшава): авто от европейских дилеров под ключ, автоподбор по Польше,
техосмотр, регистрация и номера, доставка по Европе, страхование. Языки — русский и польский.

Заявки с формы на сайте приходят в Telegram-бот: менеджеры видят карточку заявки и отмечают статус кнопками.

## Что внутри

```
daauto-site/          сайт — эту папку выкладывают на хостинг
  index.html          страница (русский текст)
  styles.css          стили
  script.js           анимации, форма, польский словарь PL
  send.php            приём заявки с формы → сохранение → рассылка в Telegram
  bot.php             Telegram-бот: команды и кнопки (вебхук)
  setup.php           подключение бота к Telegram, открывается один раз
  lib/core.php        общий код бота
  data/               заявки и подключённые чаты (создаётся на сервере)
  config.example.php  образец настроек → копируется в config.php
  README.md           подробная настройка бота и хостинга
  start-site.bat      просмотр сайта на компьютере
dev/                  проверка бота на компьютере, без хостинга (на хостинг не нужна)
  test-bot.bat        сайт на http://localhost:8090 + настоящий Telegram-бот
  share-site.bat      временная публичная ссылка на сайт (открыть с телефона)
  poll.php, router.php, share.py, make-cacert.py — служебные скрипты
```

Сборки нет: обычные HTML, CSS, JS и PHP.

## Возможности

**Сайт**
- Русский и польский. Язык выбирается так: `?lang=pl` в адресе → прошлый выбор посетителя → язык браузера.
- Адаптивная вёрстка, проверена на ширине от 320 до 1920 px.
- Карта Google с офисом (ul. Landwarowska 2, Warszawa), кнопки «Проложить маршрут» и «Открыть в Google Картах».
- Кнопки в разделах услуг («Узнать цену», «Записаться») сами выбирают нужную услугу в форме.

**Telegram-бот**
- Заявка приходит карточкой: имя, телефон, услуга, язык, комментарий, время.
- Кнопки под карточкой: 🙋 Беру в работу → ✅ Сделка / ❌ Отказ, 💬 WhatsApp. Статус и имя менеджера обновляются у всех.
- Сотрудники подключаются командой `/start <код доступа>` — в личку или в общую группу.
- Команды: `/new`, `/work`, `/leads`, `/lead_12`, `/stats`, `/stop`.

**Защита**
- Токен бота, код доступа и секрет вебхука хранятся только на сервере, в `config.php`.
- `bot.php` принимает только запросы с секретом вебхука.
- Форма: скрытое поле-ловушка для ботов, не больше 5 заявок с одного IP за 10 минут, проверка `Origin`.
- `.htaccess` закрывает служебные файлы и папки `lib/`, `data/`.

## Быстрый старт

### Посмотреть сайт

Нужен [Python](https://www.python.org/). Дважды щёлкните `daauto-site\start-site.bat` — сайт откроется
на http://localhost:8080. Форма заявок здесь не отправляется: для неё нужен PHP.

### Проверить бота на компьютере

1. Создайте бота у [@BotFather](https://t.me/BotFather).
2. Скопируйте `daauto-site\config.example.php` в `daauto-site\config.php` и заполните поля.
3. Положите PHP в `dev\php\` (см. ниже).
4. Дважды щёлкните `dev\test-bot.bat`. Сайт откроется на http://localhost:8090, в окне будет ссылка для подключения к боту.

Чтобы открыть сайт с телефона: держите открытым `test-bot.bat` и запустите `dev\share-site.bat`,
он выдаст ссылку вида `https://….trycloudflare.com`. При каждом запуске ссылка новая.

### Выложить на хостинг

Нужен хостинг с **PHP 7.4+** и **HTTPS**. GitHub Pages и Netlify не подойдут: на них PHP не работает,
и форма заявок не сможет ничего отправить.

Коротко: выложить содержимое `daauto-site/` вместе с `config.php`, дать PHP право записи в `data/`,
открыть `https://ваш-сайт/setup.php?key=<webhook_secret>`. Пошагово, с ошибками и их решениями —
в [daauto-site/README.md](daauto-site/README.md).

## Чего нет в репозитории

| Что | Почему | Где взять |
| --- | --- | --- |
| `daauto-site/config.php` | токен бота и коды доступа | создать из `config.example.php` |
| `daauto-site/data/*` | заявки клиентов | создаётся на сервере сам |
| `dev/php/` | портативный PHP, ~70 МБ | [windows.php.net](https://windows.php.net/download/): PHP 7.4+ NTS x64 (zip) распаковать в `dev\php\`, в `php.ini` включить `extension=curl`, `mbstring`, `openssl` |
| `dev/cloudflared.exe` | программа туннеля, ~55 МБ | [cloudflared-windows-amd64.exe](https://github.com/cloudflare/cloudflared/releases), сохранить как `dev\cloudflared.exe` |
| `dev/data/`, логи | тестовые заявки и логи проверки | создаются сами |

- [ ] Вписать настоящие телефон, e-mail и ссылки на мессенджеры. Сейчас стоят заглушки `+48 000 000 000` и `kontakt@daauto.pl` — в `index.html` и в тексте ошибки в `script.js`.
- [ ] Создать бота, заполнить `config.php`, после выкладки отправить тестовую заявку.
- [ ] Заменить фото с Unsplash на свои.
- [ ] Добавить политику конфиденциальности (ссылка в подвале пока пустая).
- [ ] Если появится баннер согласия на cookie (RODO), показывать карту Google только после согласия.
- [ ] Домен и хостинг.
