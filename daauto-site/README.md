# DaAuto — сайт

Файлы:

| Файл | Что это |
| --- | --- |
| `index.html`, `styles.css`, `script.js` | сам сайт |
| `send.php` | принимает заявку с формы, сохраняет и рассылает в Telegram |
| `bot.php` | Telegram-бот: команды и кнопки статуса (Telegram сам вызывает этот файл) |
| `setup.php` | подключает бота к Telegram, открывается один раз |
| `lib/core.php` | общий код бота |
| `data/` | заявки и список подключённых чатов (`store.php`), создаётся сам |
| `config.example.php` | образец настроек |

## Что умеет бот

- Заявка с сайта приходит карточкой: имя, телефон, услуга, язык, комментарий, время.
  Под ней — кнопки **🙋 Беру в работу** → **✅ Сделка** / **❌ Отказ** и **💬 WhatsApp**.
  Статус и имя менеджера обновляются в карточке у всех сразу — видно, кто какую заявку взял.
- Получают заявки все, кто подключился командой `/start <код доступа>` — себе в личку или в общую группу.
- Команды: `/new` — никто не взял, `/work` — в работе, `/leads` — последние 10,
  `/lead_12` — открыть заявку №12, `/stats` — статистика, `/stop` — отключиться.

## Настройка (≈10 минут)

1. **Создайте бота.** В Telegram: @BotFather → `/newbot` → имя. Он пришлёт токен вида
   `1234567890:AA...` — никому его не показывайте.

2. **Заполните настройки.** Скопируйте `config.example.php` в `config.php` и впишите:
   - `bot_token` — токен от BotFather;
   - `access_code` — код для сотрудников, например `daauto-7f3k9q2m` (латиница, цифры, `-`, `_`);
   - `webhook_secret` — длинная случайная строка из латиницы и цифр, 32+ символа.

   `chat_id` можно оставить пустым — чаты подключаются через `/start`.

3. **Выложите на хостинг** все файлы, включая `config.php`, `.htaccess` и папки `lib/`, `data/`.
   Нужен хостинг с PHP 7.4+ и **HTTPS** (Telegram не работает с сайтами без сертификата).
   PHP должен иметь право записи в папку `data/`.

4. **Подключите бота.** Откройте `https://ваш-сайт/setup.php?key=<webhook_secret>`.
   Страница покажет «✅ Бот подключён» и две ссылки-приглашения: в личку и в группу.

5. **Подключите менеджеров.** Отправьте им ссылку из шага 4 (или код: `/start <код>` боту).
   Для группы: ссылка «в группу» добавит бота и сразу подключит её.
   Ссылки содержат код доступа — давайте их только сотрудникам.

6. **Проверьте:** отправьте заявку с сайта — в Telegram придёт карточка с кнопками.

Чтобы сменить код доступа — поменяйте `access_code`; уже подключённые чаты останутся.
Отключить чат — `/stop` в нём.

## Проверка на компьютере, до хостинга

Бота можно проверить с настоящим Telegram прямо сейчас — хостинг и HTTPS не нужны.

1. Создайте бота и заполните `config.php` (шаги 1–2 выше).
2. Дважды щёлкните `dev\test-bot.bat` (папка `dev` — рядом с `daauto-site`).
3. В окне появятся ссылка-приглашение и адрес сайта http://localhost:8090 (откроется сам).
   Подключитесь по ссылке, отправьте заявку с сайта, понажимайте кнопки.
   В окне видно каждое сообщение и нажатие, которое дошло до бота.
4. Закройте окно — проверка остановится.

Как это устроено: на хостинге Telegram сам вызывает `bot.php`. Дома до компьютера он
не достучится, поэтому скрипт `dev\poll.php` раз в несколько секунд забирает новые
события из Telegram и передаёт их в `bot.php`. Код бота — тот же, что пойдёт на хостинг.

- Тестовые заявки хранятся в `dev\data\`, а не в `daauto-site\data\` — на сайт не попадут.
- Если бот уже подключён к сайту на хостинге, скрипт спросит, можно ли временно его отключить.
  После проверки откройте на хостинге `setup.php?key=...` — всё вернётся.
- Нужны Python (как для `start-site.bat`) и интернет с доступом к Telegram.
  PHP лежит в `dev\php\` и в git не хранится.
- Ошибки сервера пишутся в `dev\php-server.log`.

## Если не работает

Ответ сервера виден в браузере: F12 → Network → `send.php`.

| Ошибка | Что значит |
| --- | --- |
| `not_configured` | `config.php` нет на сервере или пустой `bot_token` |
| `no_recipients` | ни один чат ещё не подключён — сделайте шаги 4–5 |
| `telegram` | Telegram не принял сообщение: неверный токен, бота удалили из группы |
| `storage` | PHP не может писать в папку `data/` и `chat_id` не задан |
| `rate_limit` | больше 5 заявок с одного адреса за 10 минут — защита от спама |
| `origin` | запрос пришёл не с вашего сайта |

Кнопки или команды не отвечают — откройте `setup.php?key=...` ещё раз: внизу будет
«Последняя ошибка Telegram», если он не может достучаться до `bot.php`.

## Защита

- Токен, код доступа и секрет — только на сервере, в `config.php`; в коде страницы их нет.
- `bot.php` принимает запросы только с секретом вебхука — подделать нажатие кнопки нельзя.
- Кнопки и команды работают только в подключённых чатах. 5 неверных кодов — блок на час.
  В личке сообщение с кодом бот сразу удаляет.
- Заявки хранятся в `data/store.php`: первая строка файла — PHP-заглушка, поэтому его нельзя
  скачать даже там, где `.htaccess` не работает (nginx).
- Форма: скрытое поле-ловушка `website`, не больше 5 заявок с IP за 10 минут, проверка `Origin`.

## Что поменять перед запуском

- Телефон, e-mail, ссылки на мессенджеры (заглушки `+48 000 000 000`, `kontakt@daauto.pl`) — в `index.html`
  и в тексте ошибки в `script.js`.
- Польские тексты — словарь `PL` в начале `script.js`.
